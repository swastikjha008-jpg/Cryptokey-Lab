## ✨ What it does

Click a button, get a real keypair:

- **Solana** — an Ed25519 keypair via `@solana/web3.js`
- **Ethereum** — a secp256k1 wallet (address, private key, mnemonic) via `ethers.js`

Everything runs client-side in the browser. There's no backend, no API route, no database — the "generate" button calls the same key-generation code the underlying libraries ship for real wallets.

## 🚀 Getting started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## 📦 Build for production

```bash
pnpm build
pnpm start
```

## ⚠️ Security notes

- Every key you generate here is random and holds **zero funds** — this is a learning tool, not a wallet.
- Never fund a key generated by code you haven't audited yourself.
- Never paste a real seed phrase or private key into any website, including this one.
